### 📊 一、数据集总体信息

| 项目 | 描述 |
|------|------|
| **数据集名称** | 农业害虫检测数据集（Agricultural Pest Detection Dataset） |
| **采集方式** | 灯诱杀虫灯 / 虫情测报仪自动拍摄 |
| **图像来源** | 农业高校实地田间监测设备 |
| **标注人员** | 农业昆虫学教授团队（人工精细标注） |
| **总图像数量** | **2,178 张** |
| - 带标注图像 | 576 张（用于训练/验证） |
| - 未标注图像 | 1,602 张（可用于测试、无监督学习或人工复核） |
| **标注格式** | ✅ YOLO TXT 格式<br>✅ COCO JSON 格式 |
| **任务类型** | 目标检测（Object Detection） |
| **应用场景** | 智能虫情监测、农业病虫害预警、自动化植保 |

### 📁 四、推荐使用建议

| 目的 | 建议策略 |
|------|----------|
| **基础训练** | 使用 576 张标注图划分 train/val（如 8:2） |
| **处理类别不平衡** | 对稀有类（ID 24, 27）使用 **过采样 + 数据增强**（旋转、裁剪、色彩扰动） |
| **模型选择** | 推荐 YOLOv8s/m 或 RT-DETR（对小目标更友好） |
| **未标注图像利用** | 可用于：<br>• 半监督学习（如 Soft Teacher）<br>• 人工复核补充标注<br>• 测试模型泛化能力 |
| **评估重点** | 关注 mAP@0.5 与 **Recall（召回率）**，避免漏检关键害虫 |
